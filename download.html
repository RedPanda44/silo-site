Before you start

System requirements

PC

  • Windows 10 or Windows 11, 64-bit
  • Roughly 10 MB of free disk space
  • No .NET, Python or WebView runtimes

Device

  • iPhone running iOS 18 or newer (16–17 via legacy cache)
  • Unlocked during every session
  • Lightning or USB‑C cable for first pairing

Software

  • Apple Mobile Device Support (64-bit iTunes)
  • Optional: 3uTools for driver repair
  • Optional: Apple Devices app for Wi‑Fi sync
Installation

Up and running in three steps

Download the file

Save silo-installer.exe anywhere — Downloads or Desktop. It is a single file; there is nothing else to download.

Connect & trust

Plug in your iPhone, unlock it, and tap Trust this Computer if prompted. Apple Mobile Device Support must be installed.

Install & launch

Run silo-installer.exe and click Install — Silo lands in %LOCALAPPDATA%\Programs\Silo in seconds, no admin needed. Windows SmartScreen may warn on first run — choose More info → Run anyway for an unsigned build.

Prefer building it yourself? The full source code lives in the AirCard repository on GitHub. With a Rust toolchain installed, run cargo test then cargo build --release — your binary lands in target\release. Full instructions in the build guide.
macOS · universal

Install Silo on a Mac

The universal build ships as a single .dmg — open it, drag Silo into Applications and you are done. Windows users can grab the installer right at the top of this page.

  • 1. Download Silo.dmg and open it.
  • 2. Drag the Silo icon into the Applications folder.
  • 3. First launch: right-click the app → Open → Open again to clear Gatekeeper.
  • 4. Connect the iPhone with a cable, tap Trust, and start theming.

Release notes

What's new in 1.5.1

A focused reliability release — no changes to your saved cards, themes or backups.

Restore that always lands

Restore Original now resolves the exact on-device card folder — padded or unpadded hash variant — before writing, so your original card face is always restored to the right place.

Cleaner transport shutdown

If the AirTraffic sync hits its timeout, the worker now cancels immediately and releases the device connection instead of leaving a stalled session holding your iPhone.

Smarter card detection

URL-safe base64 card hashes that contain - or _ separators are no longer mistaken for system strings and rejected.

Snappier previews

The card artwork channel is now persistent, so rapid rescans no longer drop the in-flight preview response.

Everything from 1.5.0

The full Wallet-inspired redesign, light & dark themes, macOS-style sidebar, lock-screen keypad preview, drag & drop import and refactored UI layer.

Unchanged compatibility

Same requirements as 1.5.0 — Windows 10/11 64-bit, iOS 18+, Apple Mobile Device Support. Existing settings and backups carry over untouched.
