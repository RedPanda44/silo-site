Requirements

  • Windows 10 / 11 (64-bit)
  • Apple Mobile Device Support / 64-bit iTunes — required for Apple device communication.
  • A Lightning or USB‑C cable for the initial trust/pairing setup.
  • For Wi‑Fi mode: Wi‑Fi sync enabled, with the PC and iPhone on the same local network.
Silo itself needs nothing else — no Python, no .NET, no WebView2. The whole app is one Silo.exe.

Installation

Pre-built executable

  1. Download Silo.exe from the download page or Releases.
  2. Connect your iPhone via USB, unlock it, and tap Trust this Computer if prompted.
  3. Run Silo.exe. After Wi‑Fi sync is enabled, later sessions can work without the cable.

Windows may show a SmartScreen warning for unsigned builds. Choose More info → Run anyway. You can verify integrity against the published SHA-256 on the download page.

Troubleshooting & driver repair

iPhone not detected, AirTraffic sync hangs, or an operation fails? Corrupted or conflicting Apple USB drivers on Windows are the #1 root cause.
  1. Download and install 3uTools.
  2. Disconnect your iPhone from your PC.
  3. In 3uTools, go to Toolbox → Repair Driver.
  4. Click Repair Now and wait for the Apple driver reinstallation to finish.
  5. Reconnect your unlocked iPhone, tap Trust, and launch Silo.

If the problem persists, also try: a different cable or USB port (avoid unpowered hubs), closing iTunes/Apple Devices/iMazing so nothing else holds the device, and restarting the Apple Mobile Device Service.

Wi‑Fi connection setup

  1. Connect the iPhone by USB for the initial pairing.
  2. In Apple Devices or iTunes, enable Show this iPhone when on Wi‑Fi / Sync with this iPhone over Wi‑Fi.
  3. Apply the setting, then keep the iPhone and PC on the same local network.
  4. In Silo, click Refresh and confirm the device shows a WiFi transport.
  5. Disconnect the cable, click Refresh again, and select WiFi only. Use Auto (USB preferred) when automatic fallback is desired.
Why does this matter? If both transports are available, Auto uses USB first and falls back to Wi‑Fi. For a guaranteed end-to-end Wi‑Fi route, disconnect the USB cable, click Refresh, then choose Wi‑Fi only. Apple's AirTraffic API selects its route by UDID rather than accepting a transport parameter.

How to customize Apple Wallet cards

  1. Connect your iPhone through USB or paired Wi‑Fi and make sure it is unlocked.
  2. In Silo, stay on the Wallet tab and click Scan.
  3. On your iPhone:
    • Open Apple Wallet (or double-click the Side/Power button).
    • Tap the card you want to customize.
    • Silo intercepts and saves the card hash automatically. Click Stop.
  4. Click Choose Image… to pick your artwork (PNG, JPG or WebP — drag inside the preview to position the crop, then scale it to 1536 × 969).
  5. Click Apply Card Skin.
  6. Force-close the Wallet app on your iPhone from the App Switcher (swipe up from the bottom, then swipe Wallet away) and reopen Wallet to see your new card.
  7. The first apply stores a local backup of the original card face. Use Restore Original later to write it back and invalidate Wallet's cached artwork.

Tip: drop artwork anywhere on the Silo window to load it — no file dialog needed.

How to apply lock-screen passcode themes (.passthm)

  1. Switch to the Passcode tab in Silo.
  2. Click Choose .passthm… and select any .passthm package (Cowabunga or Nugget).
  3. Select your target iOS version cache:
    • Auto (TelephonyUI-10) — iOS 18+ (default)
    • TelephonyUI-9 — iOS 16 – 17
    • TelephonyUI-8 — legacy iOS
  4. Click Apply Passcode Theme.
  5. Lock your iPhone screen or open the Phone dialer to see your new custom passcode keypad buttons.
Turn OFF Bold Text. On your iPhone go to Settings → Display & Brightness and make sure Bold Text is off. With Bold Text enabled, iOS ignores cached dialer button graphics and renders system vector fonts instead — your theme will appear not to work.

Drop a .passthm file anywhere on the Silo window to open it directly in the Passcode studio.

Safety & restore

  • No jailbreak. Silo uses Apple's built-in AirTraffic sync conduit and never modifies system partitions or disables security.
  • Books-state snapshot. Before writing, a complete snapshot of the affected Books state is captured so the original device state can be restored.
  • Card face backup. The original Wallet card face is stored locally on first apply; Restore Original writes it back and invalidates Wallet's cached artwork.
  • Reversible. Every theming operation can be undone from the app itself — no DFU, no re-restore.

Building from source

Want to compile it yourself? The complete source code lives in the AirCard repository on GitHub. Prerequisites: Rust toolchain with stable-x86_64-pc-windows-msvc.

# Clone the AirCard repository
git clone https://github.com/Lumid-Off/AirCard-Windows.git
cd AirCard-Windows

# Run tests
cargo test

# Build release binary
cargo build --release

The compiled binary will be in target\release. Release builds use LTO, a single codegen unit and stripped symbols for a small, fast executable.

Changelog

1.5.1 — current

  • Safer restores: Restore Original resolves the exact on-device card folder (padded/unpadded hash variant) before writing, so it always targets the correct card.
  • Cleaner transport shutdown: the AirTraffic sync worker cancels promptly on timeout and releases the device connection instead of leaving a stalled session.
  • Smarter card detection: URL-safe base64 hashes containing -/_ separators are no longer rejected.
  • Snappier previews: the card artwork channel is persistent, so rapid rescans no longer drop the in-flight response.

1.5.0

  • Complete UI redesign — Apple Wallet-inspired interface with elevated cards, capsule buttons, hairline separators and micro-animations.
  • Light & dark themes, switchable from the top bar or Settings and saved locally.
  • New macOS-style sidebar with animated selection, app badge and a docked device status card.
  • Lock-screen keypad preview in the Passcode Studio, rendered inside a realistic device screen with clock and circular key backplates.
  • Drag & drop import for artwork (PNG/JPG/WebP) and .passthm packages.
  • Refactored UI layer split into theme, icons, widgets and one file per page; version read from a single source of truth; Settings gained an Appearance section.

Earlier releases and pre-releases are listed on GitHub Releases.
